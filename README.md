# NamuWiki Trend Monitor

**나무위키 실시간 검색어 TOP 10을 주기적으로 확인하고, 새롭게 등장한 검색어를 데스크톱 알림으로 알려주는 Chrome 확장 프로그램입니다.**

검색어 순위를 팝업에서 확인할 수 있으며, 각 검색어의 **`이유`** 링크를 통해 아카라이브 *나무위키 실검 알려주는 채널*의 관련 검색 결과로 이동할 수 있습니다.

## 주요 기능

### 1. 실시간 검색어 TOP 10 표시

- 나무위키의 실시간 검색어 1~10위를 확장 프로그램 팝업에 표시합니다.
- 검색어를 클릭하면 해당 나무위키 검색 페이지가 열립니다.
- **오늘 처음 관측되었고 가장 최근 수집에서 새롭게 등장한 검색어**에는 `NEW` 배지를 표시합니다.
- 마지막으로 수집한 시각을 확인할 수 있습니다.

### 2. 사용자 지정 자동 수집 간격

팝업에서 검색어 수집 간격을 선택하고 저장할 수 있습니다.

| 수집 간격 | 비고 |
| --- | --- |
| 5분 | 자주 확인하고 싶을 때 |
| **15분** | **기본 설정** |
| 30분 | 알림과 수집 빈도를 줄이고 싶을 때 |
| 60분 | 가볍게 모니터링하고 싶을 때 |

- 설정은 Chrome 로컬 저장소에 유지됩니다.
- Chrome을 새로 시작하면 즉시 한 번 수집을 시도하며, 이후 설정한 간격으로 자동 수집합니다.
- 수집 간격을 변경하면 다음 수집 일정이 새 간격에 맞춰 다시 설정됩니다.

### 3. 신규 검색어 데스크톱 알림

- 오늘 처음 관측한 검색어가 나타나면 데스크톱 알림을 보냅니다.
- 같은 검색어가 TOP 10에서 사라졌다가 **같은 날 다시 진입해도 중복 알림을 보내지 않습니다.**
- 한 번에 신규 검색어가 여러 개 발견되면 **하나의 알림**으로 묶습니다.
- 알림에는 최대 3개의 검색어와 순위를 표시하며, 더 많으면 나머지 개수를 안내합니다.
- 알림 전송이 실패하면 대기 목록에 보관했다가 다음 수집에서 재시도합니다.

> 최초 실행에서는 당시 TOP 10을 기준 목록으로 저장하므로, 처음부터 검색어 10개에 대한 알림을 보내지는 않습니다. 알림 표시 시간은 Chrome과 운영체제의 알림 설정에 따라 달라질 수 있습니다.

### 4. 실검 관련 글 찾아보기

- TOP 10의 각 검색어 오른쪽에 **`이유`** 링크를 제공합니다.
- 클릭하면 [아카라이브 나무위키 실검 알려주는 채널](https://arca.live/b/namuhotnow)에서 해당 검색어의 검색 결과를 새 탭으로 엽니다.

> `이유`는 관련 게시글을 **검색하는 바로가기**입니다. 확장 프로그램이 실검에 오른 원인을 자체적으로 분석하거나 검증하는 기능은 아닙니다. 검색 결과가 없거나 현재 이슈와 무관한 글이 표시될 수 있습니다.

### 5. 임시 탭 자동 정리

- 수집 시 나무위키 페이지를 **비활성 탭**으로 열어 검색어를 확인합니다.
- 수집에 성공하면 해당 탭을 닫습니다.
- 응답이 없거나 수집에 실패한 경우를 대비해 **약 30초 후 정리 알람**을 실행합니다.

> 비활성 탭은 Chrome 탭 표시줄에 잠시 보일 수 있으며, 브라우저 상태에 따라 정리 시점이 지연될 수 있습니다.

## 설치 방법

Chrome 웹 스토어 배포 버전이 아닌 **소스 코드 설치 방식**입니다.

1. GitHub 저장소에서 **Code → Download ZIP**으로 프로젝트를 내려받고 압축을 풉니다. Git을 사용한다면 저장소를 클론해도 됩니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 활성화합니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭합니다.
5. `manifest.json`이 들어 있는 **`namuwiki-trend-monitor` 폴더**를 선택합니다.
6. Chrome 도구 모음의 **NamuWiki Trend Monitor** 아이콘을 클릭합니다.

별도의 서버 실행이나 패키지 설치 과정은 필요하지 않습니다.

## 사용 방법

1. 확장 프로그램 팝업에서 최근 수집한 **실시간 검색어 TOP 10**을 확인합니다.
2. 팝업의 **자동 수집 설정**에서 원하는 간격(5·15·30·60분)을 선택하고 **저장**을 누릅니다.
3. 새로운 검색어가 감지되면 Windows 등 운영체제의 데스크톱 알림으로 알려줍니다.
4. 검색어를 클릭하면 나무위키로 이동하고, **`이유`**를 클릭하면 아카라이브 채널의 검색 결과가 열립니다.

**알림이 보이지 않는다면** Windows 알림 설정에서 Chrome 알림이 허용되어 있는지, 방해 금지 모드가 켜져 있는지 확인해 주세요.

## 기술 스택

| 구분 | 사용 기술 |
| --- | --- |
| 확장 프로그램 | Chrome Extension (Manifest V3) |
| 언어 | JavaScript, HTML, CSS |
| 백그라운드 실행 | Chrome Service Worker, `chrome.alarms` |
| 데이터 저장 | `chrome.storage.local`, `chrome.storage.session` |
| 페이지 데이터 수집 | Content Script, DOM API |
| 프로세스 간 통신 | `chrome.runtime.sendMessage` |
| 데스크톱 알림 | `chrome.notifications` |

```text

    ├── manifest.json        # 확장 프로그램 설정 및 권한
    ├── background.js        # 수집 주기, 검색어 비교, 알림, 임시 탭 관리
    ├── content.js           # 나무위키 실시간 검색어 TOP 10 추출
    ├── popup.html           # 팝업 화면 구조
    ├── popup.css            # 팝업 스타일
    ├── popup.js             # 검색어 표시 및 수집 간격 설정
    └── icons/
        └── icon128.png      # 확장 프로그램 및 알림 아이콘
```

## 알아두기

- 실시간 검색어는 설정한 **수집 시점의 TOP 10**만 확인합니다. 두 번의 수집 사이에 잠깐 나타났다가 사라진 검색어는 놓칠 수 있습니다.
- 나무위키 페이지의 HTML 구조가 바뀌면 수집 기능이 영향을 받을 수 있습니다.
- Chrome이 완전히 종료된 동안에는 주기적으로 수집하지 않습니다.
- 아카라이브 관련 글은 커뮤니티 게시물이므로 정확성과 최신성을 별도로 확인해 주세요.
- 이 프로젝트는 개인이 제작한 **비공식 확장 프로그램**이며, 나무위키 또는 아카라이브의 공식 서비스가 아닙니다.
